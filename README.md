# Hospital Emergency Room Dashboard (Power BI)

An interactive, multi-view Power BI dashboard designed to monitor and analyze Emergency Room operational performance, patient demographics, and department resource efficiency.

### 1. Consolidated View
Provides a high-level executive overview tracking overall volume (9,216 Patients), average wait times, patient satisfaction, and core demographic distributions.

## 🛠️ Key Performance Indicators (KPIs) Captured
* **Operational Velocity:** Tracked Average Wait Times (35.3 Mins) and target benchmarks.
* **Patient Satisfaction:** Monitored baseline experience scores (4.99/5.00).
* **Staffing Intelligence:** Matrix layout mapping patient volume by Day and Hour to optimize healthcare shift scheduling.
* **Demographics & Routing:** Deep-dive charts organizing entries by Gender, Age Group, Race, and Department Referrals.
